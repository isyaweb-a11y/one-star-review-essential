## The entry

`main.py` writes one single-line one-star review to
`/output/entry.txt` — a deadpan complaint filed in earnest against
gravity, an everyday essential that cannot be fixed:

> Gravity gets one star: it has never once missed a dropped phone, a spilled coffee or a falling toast, and it has never once caught any of them.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Stdlib only, no network access, no files read outside this repository.
